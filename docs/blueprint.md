# **App Name**: HassaniVerse

## Core Features:

- 3D Immersive World: Create a fully immersive 3D world using Three.js or React-Three-Fiber with floating islands, holographic elements, and interactive camera movements. Make the camera react to mouse movement + scrolling. Include neon effects, glowing icons, particles, and smooth animations.
- Dynamic Content from Firestore: Fetch and display all dynamic content from Firestore, including profile information, education details, skills, projects, books, certificates, gallery, courses, and social links.  Implement contact form using Firestore.
- Multilingual Support: Implement full Arabic and English support with auto LTR/RTL switching and a language toggle button. Store all text in Firestore for easy management.
- Interactive Hero Section: Develop a hero section with floating 3D frames, glowing text, neon buttons for CV download and WhatsApp contact, floating social icons, particle effects, holographic rings, and camera movement based on cursor and scroll.
- 3D Skill Showcase: Design a glowing dome containing rotating 3D icons for each skill, including web development, programming languages, tools, databases, design, and soft skills.
- Project Starfield: Create a space-themed 3D starfield where each project is displayed as a rotating 3D cube with project screenshots, titles, descriptions, live links, and technology icons. Pull data for projects from Firestore.
- AI-Powered Book Recommendations: Generate book recommendations tool that suggests other titles user would like based on previously ordered books using gen AI.

## Style Guidelines:

- Primary color: Electric blue (#7DF9FF) for a modern, high-tech feel.
- Background color: Dark purple (#1A237A) at 20% saturation for a deep, immersive backdrop.
- Accent color: Cyan (#00FFFF) to highlight interactive elements and create visual interest.
- Headline font: 'Space Grotesk', a modern sans-serif, for headlines. Body text: 'Inter' for readability. (sans-serif).
- Use glowing, minimalist icons to represent skills, technologies, and social media links.
- Design floating 3D elements with glassmorphism UI components for a futuristic look.
- Implement smooth transitions and camera movements between 3D islands to enhance user experience.
