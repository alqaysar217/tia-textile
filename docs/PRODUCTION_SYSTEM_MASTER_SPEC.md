# وثيقة المواصفات الفنية - نظام إدارة الإنتاج (الجمعية النسيجية)

## 1. فلسفة النظام
النظام مبني على مفهوم **الإنتاج بالمراحل (Process Costing)** مع احتساب **الأجور بالقطعة (Piece-Rate System)**.

## 2. الدورة التشغيلية (Workflow)
1. **أمر الإنتاج (Production Order)**: تحديد المنتج النهائي (مثلاً: 300 معوز ملكي).
2. **المراحل (Stages)**:
   - **المرحلة 1 (الخياطة)**:
     - سند صرف مواد (خيوط) للعامل.
     - سند استلام إنتاج (معاوز مخيطة).
     - احتساب أجر العامل بناءً على الكمية المقبولة.
     - تسجيل المرتجع والتالف.
   - **المرحلة 2 (التكريز/التطريز)**: تنتقل القطع المستلمة من المرحلة 1 كمدخلات للمرحلة 2.
   - **المرحلة 3 (التلوين/الصباغة)**: إضافة تكاليف مواد الصبغة.
   - ... وهكذا حتى (التغليف).

## 3. احتساب التكلفة (Costing Model)
تكلفة القطعة الواحدة = 
   (إجمالي قيمة المواد الخام المستهلكة في كل المراحل) 
   + (إجمالي أجور العمال في كل المراحل) 
   + (المصاريف غير المباشرة: كهرباء، إهلاك، إيجار)
   ÷ (عدد القطع الجاهزة النهائية).

## 4. نظام السندات (Vouchers)
- **سند صرف مواد**: (من المخزن -> عهدة العامل).
- **سند استلام إنتاج**: (من العامل -> مخزن الإنتاج تحت التشغيل/المرحلة التالية).
- **سند تسوية مواد**: (مرتجع أو تالف من العامل).
- **سند استحقاق أجر**: (يولد آلياً عند استلام الإنتاج).

## 5. حالة المنتج
- **تحت التشغيل (WIP)**: المنتج في أي مرحلة قبل التغليف النهائي.
- **منتج جاهز (Finished Good)**: المنتج بعد اجتياز المرحلة الأخيرة (يظهر في الكتالوج للبيع).
